Panduan Provider Role

Setiap provider bisa punya role berbeda. Klik badge role di tabel provider untuk toggle.

  • chat Provider untuk menjawab pertanyaan user (LLM utama)
  • embedding Provider untuk RAG semantic (ubah teks jadi vector)
  • enrichment Provider untuk ekstrak triple ke Knowledge Graph
  • query-rewriter Provider untuk rewrite pertanyaan user
Saran kombinasi:
  • Gemini: chat + embedding + enrichment (paling fleksibel)
  • Groq: chat + query-rewriter (tercepat)
  • Mistral: chat + enrichment (fallback)
Tambah Provider AI

Pilih provider terdaftar, atau tambahkan provider custom dengan Custom Endpoint jika ingin pakai provider OpenAI-compatible lainnya.

Cara dapat API key gratis:
  • Gemini: aistudio.google.com/app/apikey
  • Groq: console.groq.com/keys
  • OpenRouter: openrouter.ai/keys
  • Cerebras: cloud.cerebras.ai
  • Together: api.together.xyz
  • Mistral: console.mistral.ai
  • DeepSeek: platform.deepseek.com
  • xAI Grok: console.x.ai
Provider Custom OpenAI-Compatible: Isi endpoint dengan format https://api.contoh.com/v1. Sistem akan otomatis kirim request ke {endpoint}/chat/completions.
